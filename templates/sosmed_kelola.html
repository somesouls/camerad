Kelola Data Sosmed

Kumpulkan percakapan dari media sosial (X, Instagram, TikTok) untuk dianalisis: deteksi topik/jenis layanan, sentimen, dan pemasangan pertanyaan–jawaban. Sumber data bisa lewat impor manual (ekspor/CSV/JSON) atau tarik otomatis dari X, Instagram, dan TikTok lewat kolektor browser (tanpa ekstensi).

Tarik dari X (Twitter)

Mengumpulkan mention/percakapan ke akun resmi otomatis lewat kolektor browser (tanpa ekstensi). Kosongkan tanggal untuk menarik H-1 (kemarin). Data langsung di-ingest & anti-dobel.

Memeriksa status…

Penjadwal harian otomatis (H-1) aktif bila SOSMED_X_SCHEDULER=1 di server — jam & zona waktu diatur lewat SOSMED_X_INGEST_HOUR/MINUTE & SOSMED_X_TZ (default Asia/Jakarta). Tarikan lewat X API lama sudah tidak dipakai (free tier tak bisa baca mention).

Tarik dari Instagram

Mengumpulkan komentar pada beberapa postingan TERBARU akun resmi otomatis lewat kolektor browser (tanpa ekstensi). Kosongkan tanggal untuk menandai H-1. Data langsung di-ingest & anti-dobel.

Memeriksa status…

Penjadwal harian aktif bila SOSMED_IG_SCHEDULER=1 — jam via SOSMED_IG_INGEST_HOUR/MINUTE. Instagram tak punya pencarian per-tanggal publik, jadi kolektor menarik komentar pada SOSMED_IG_MAX_POSTS postingan terbaru; anti-dobel menjaga hanya komentar baru tersimpan. Butuh login akun kedua di server (SOSMED_IG_USERNAME/PASSWORD) atau sesi tersimpan, dan target di SOSMED_IG_TARGET.

Impor Manual

Unggah berkas hasil ekspor (.json / .jsonl / .csv / .zip) atau tempel langsung. Payload mentah X API v2 (punya data & includes) otomatis dikenali.

Riwayat Impor / Tarik

“Perbaiki pemasangan Q&A” menjalankan ulang perajutan pertanyaan–jawaban sadar-thread untuk seluruh data lama. Gunakan sekali setelah pembaruan sistem bila ada tweet jawaban yang keliru tercatat sebagai pertanyaan. Aman dijalankan berulang.

“Index data baru” membangun index vektor pencarian cepat sosmed secara inkremental — hanya meng-embed Q&A terjawab yang baru/berubah. Berjalan otomatis di latar tiap ada impor/tarik/perbaikan; tombol ini untuk memicu manual. Aman diklik berulang.
