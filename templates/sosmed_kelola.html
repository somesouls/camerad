Kelola Data Sosmed

Kumpulkan percakapan dari media sosial (X, Instagram, TikTok) untuk dianalisis: deteksi topik/jenis layanan, sentimen, dan pemasangan pertanyaan–jawaban. Sumber data bisa lewat impor manual (ekspor/CSV/JSON) atau tarik langsung dari X API.

Tarik dari X (Twitter)

Menarik mention/percakapan ke akun resmi. Ketersediaan bergantung tier X API pada kredensial server.

Memeriksa kapabilitas…

Free tier X API umumnya tidak bisa membaca mention/pencarian (butuh Basic+). Jika ditolak, gunakan impor manual di samping.

Impor Manual

Unggah berkas hasil ekspor (.json / .jsonl / .csv / .zip) atau tempel langsung. Payload mentah X API v2 (punya data & includes) otomatis dikenali.

Riwayat Impor / Tarik

“Perbaiki pemasangan Q&A” menjalankan ulang perajutan pertanyaan–jawaban sadar-thread untuk seluruh data lama. Gunakan sekali setelah pembaruan sistem bila ada tweet jawaban yang keliru tercatat sebagai pertanyaan. Aman dijalankan berulang.
