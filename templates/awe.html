Tarik Data Langsung Tanpa Extension

Pilih rentang tanggal lalu Cek Ketersediaan. Jika data tanggal itu sudah ada, cukup buka dashboard — tak perlu tarik ulang. Jika belum ada, masukkan username & password AWE untuk menariknya. Kredensial tidak disimpan; jika sesi logout, harus masukkan lagi.

Kredensial hanya dipakai untuk sesi tarik ini dan langsung dilupakan server (tidak ditulis ke disk/DB).
Catatan teknis: server login (CSRF handshake → signin) lalu memutar ulang endpoint Ultra/Platform yang sama seperti extension. Penurunan token sesi Impact360AuthToken murni server-side perlu satu kali validasi di jaringan intranet; bila gagal, unggah JSON manual tetap tersedia di atas.
