🔴 Mode B · streaming real-time + barge-in

Streaming: mati

Percakapan langsung lewat WebSocket: mikrofon streaming → VAD deteksi akhir ucapan otomatis → jawaban suara. Di awal sesi ada auto-kalibrasi noise ~1 detik (diamkan sebentar) agar ambang menyesuaikan lingkungan otomatis. Barge-in via mic (centang) dirancang tahan-gema untuk loudspeaker: browser memakai AEC/noise-suppression + gerbang noise, dan server hanya memotong bila terdeteksi bicara berkelanjutan DAN energinya melewati ambang speaking_rms (bukan blip/gema/ketikan). Saat memverifikasi kandidat suara, volume bot dikecilkan sementara (ducking) lalu dipulihkan bila ternyata noise. Bila centang dimatikan, mode half-duplex sejati: mic benar-benar dibisukan selama bot bicara (mustahil dipotong noise); tombol ✋ Potong tetap bisa. Semua ambang bisa diatur di Konfigurasi → Streaming (Mode B), dan ada tombol ↺ Reset ke rekomendasi bila setelan sudah terlanjur kacau. Level deteksi (rms vs ambang) dicatat di log di bawah.
