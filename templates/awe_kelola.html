Untuk kebutuhan harian, cukup pakai Tarik Otomatis di bawah - sekali jalan: login → tarik ke penyimpanan sementara → proses bahasa → simpan ke database AWE. Alat Manual / Lanjutan di bawahnya dipakai sesekali untuk backfill rentang lama, menarik dengan kredensial sendiri, atau memproses ulang.

Tarik Otomatis Harian

Jalur utama —

Penjadwal menarik & memproses data AWE H-1 otomatis tiap hari (mirip ingest Dialogflow). Aktifkan lewat berkas .env: isi AVAYA_USERNAME/AVAYA_PASSWORD, set AWE_SCHEDULER=1, lalu restart aplikasi. Kredensial tidak disimpan ke database (login lalu dilupakan). Tombol di bawah menjalankan tarik+proses satu kali sekarang memakai kredensial .env.

Memuat status…

Kosongkan keduanya untuk menarik kemarin (H-1) seperti jadwal otomatis. Isi salah satu untuk satu hari, atau keduanya untuk rentang tertentu (tetap memakai kredensial .env).

Manual / Lanjutan

Bersifat opsional dan dipakai sesekali. Untuk operasi harian normal, cukup Tarik Otomatis di atas - bagian ini untuk kasus khusus seperti backfill data lama, menarik dengan kredensial sendiri, atau memproses ulang.

1

Tarik Data ke Penyimpanan Sementara

ℹ️ Kapan dipakai: untuk backfill rentang lama, atau menarik dengan kredensial sendiri tanpa menyimpan password di .env. Bisa dikerjakan bertahap oleh beberapa orang.

Pilih rentang tanggal lalu Cek Ketersediaan. Hari yang sudah ada tidak perlu ditarik ulang (dedup otomatis berdasarkan sid). Untuk hari yang belum ada, masukkan kredensial AWE. Kredensial tidak disimpan.

Kredensial hanya dipakai untuk sesi tarik ini dan langsung dilupakan server (tidak ditulis ke disk/DB).
2

Pemrosesan Bahasa → Database AWE

ℹ️ Kapan dipakai: untuk memproses ulang atau memproses sebagian data di penyimpanan sementara tanpa menarik ulang. Tarik Otomatis sudah menjalankan langkah ini sendiri.

Jalankan pemrosesan bahasa (embedding, sentimen, topik, pemetaan intent, klaster) atas data di penyimpanan sementara, lalu simpan hasilnya ke database AWE. Kosongkan rentang untuk memproses seluruh isi penyimpanan.

Validasi & Perbarui NIK/NPWP

—

NIK/NPWP di-scrape dari kolom "Dialed To (DNIS)" saat penarikan dan kini disimpan sebagai kolom tersendiri untuk data baru. Gunakan panel ini untuk mengecek cakupan NIK dan memperbarui baris lama yang belum tersimpan NIK-nya - dipulihkan dari nama berformat "Nama [NIK]", lalu dari penyimpanan sementara. Nama yang masih mengandung "[...]" sekaligus dirapikan. Aman dijalankan berulang.

Klik Cek Status NIK untuk melihat ringkasan.
