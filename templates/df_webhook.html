🔌 Webhook Chatbot — Dialogflow ES

Hubungkan ChatBot Dialogflow ES (Wajib Pajak) ke mesin RAG internal. Endpoint fulfillment ini menjawab pertanyaan dengan grounding ke basis pengetahuan, dilengkapi fast-path deadline guard agar balasan tidak pernah melewati batas ~5 detik Dialogflow ES.

🔗 Endpoint Fulfillment nonaktif

Salin URL & token ini ke Dialogflow ES → Fulfillment → Webhook.
Token juga bisa dikirim lewat query ?token=... bila header tidak memungkinkan. Menekan “Ganti” membatalkan token lama.

⚙️ Pengaturan

Mode berlaku untuk profil terpilih di seluruh kanal (chatbot web /rag maupun webhook Dialogflow). Ubah mode lalu klik Simpan Pengaturan, kemudian pakai Uji Fast-Path di bawah untuk membandingkan kecepatan tiap mode.
Dialogflow ES memutus webhook pada ~5 dtk. Deadline guard 4500 ms memberi ruang balasan fallback yang sopan bila jawaban belum siap. Untuk pertanyaan berat, pengguna menerima fallback dan bisa mengulang.

🧪 Uji Fast-Path

Kirim pertanyaan langsung ke mesin (tanpa Dialogflow) untuk melihat jawaban & waktu proses terhadap deadline.

📘 Cara memasang di Dialogflow ES

  1. Buka Dialogflow ES → Fulfillment, aktifkan Webhook.
  2. Tempel Webhook URL di atas ke kolom URL.
  3. Tambahkan header: X-Camerad-Token = token di atas.
  4. Simpan. Lalu pada intent yang ingin dijawab RAG (mis. Default Fallback Intent), aktifkan Enable webhook call for this intent.
  5. Uji di simulator Dialogflow. Jawaban datang dari mesin RAG, atau kalimat fallback bila melewati deadline.
