# Camerad design system — Green × Pink v1

Design read: B2B decision intelligence with a forest-green and bright-pink editorial language. Variance 7/10, motion 4/10, density 4/10.

`static/design-system/tokens.css` is canonical. Dark foundation is `#071A14`; light foundation is `#F3FFF9`; actions are pink and secondary signals green. Do not reintroduce retired palettes or unrelated accents.

Arial/Helvetica is used throughout. Controls use 12px radius, panels 22px, and major emphasis 36px. Cards exist only where elevation communicates hierarchy. Motion uses IntersectionObserver and respects reduced motion. Theme state uses `camerad-theme`; assets use stable versioning.
